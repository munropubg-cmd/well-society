# Well Society — telehealth website

Homepage build for wellsociety.com (React + Vite + TypeScript + Tailwind, motion by framer-motion, smooth scroll by Lenis).

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Build

```bash
npm run build
```

## Notes

- Several sections are shown in more than one version (e.g. Featured treatment V1–V3, How it works V1–V2, Our approach V1–V3) for client review; the unused versions will be removed once one is chosen.
- The small "Background" pill on some sections is a review-only colour switcher, also to be removed before launch.
- Media lives in `public/media` (videos are web-encoded copies of the client's originals).
- Copy follows the LegitScript compliance rules in the build brief (no outcome guarantees, "weight management", no brand-drug names, compounded-medication disclosures).
